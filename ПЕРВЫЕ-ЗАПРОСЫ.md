# Как запускать вёрстку в Claude Code

Откройте папку `rai-site` в Claude Code и подключите Figma MCP (файл `HOnzCcOgjLU9vmar47ScwR`).

## 1. Каркас проекта
> Прочитай CLAUDE.md и rai-handoff.md. Создай проект на Astro по описанной структуре: tokens.css, base.css со шрифтами (скачай Cormorant Garamond и Onest в woff2, с кириллицей, положи в public/fonts), классы типографики с мобильными размерами через clamp(), Base-layout. Данные бери из src/data/prices.json и src/data/site.json — они уже заполнены. Логотип и иконки экспортируй из Figma в SVG (логотип — узел 214:4724, иконки — компоненты Icon/*), иконки со stroke="currentColor". Покажи структуру, ничего пока не верстай.

## 2. Секции — по одной за запрос
> Сверстай Header: desktop 198:2587, mobile 214:3649 (+ открытое меню 214:4722). Сверь со скриншотами на 1440 и 375, проверь 768. Перечисли расхождения и исправь. Закоммить.

Дальше тем же запросом по порядку: Hero → Services → Trust → Process → Pricing → Agents → Reviews → Calculator (+ шторки 235:4133, 235:4178, 235:4205) → Benefits → Faq → Guide → Contact → Footer. Node ID — в таблице CLAUDE.md.

## 3. Форма
> Сделай public/api/lead.php по разделу «Форма» в CLAUDE.md. Конфиг — по образцу public/api/config.example.php. Подключи отправку из формы Contact и из кнопки «Зафиксировать смету» (приложи смету).

## 4. Финал
> Прогони npm run build, Lighthouse mobile, проверь доступность (фокус, вкладки стрелками, шторки по Esc). Сделай страницы /privacy и /consent (пока с плейсхолдерами), deploy.sh.
